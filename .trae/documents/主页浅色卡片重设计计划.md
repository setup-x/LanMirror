# 主页浅色卡片重设计

## Context

主页目前深色文字与同权重按钮堆叠，层级不清。用户选择浅色简洁卡片：浅灰背景、白色圆角、蓝色强调。仅改主页原生布局和视觉，保留全部功能，不改发送/接收界面、SDK、权限与传输逻辑。

## 实施

- 唯一业务修改文件：app/src/main/java/com/lanmirror/app/MainActivity.java。
- home ()保留清理接收与设备发现、mode、常亮标志及四个入口原回调。使用独立renderHome及主页专用文字/卡片样式，不修改跨页面共享newPage/text/button。
- 主页采用浅灰背景和原生ScrollView；页头LanMirror/局域镜像标题、局域网投屏说明和1.8.0版本标签。
-
三张自适应高度入口卡片：蓝色强调的“多路接收”（最多4路、逐路确认）、“发送屏幕”（镜像本机屏幕）、次级“单路兼容”（配对码/旧版）。整张卡片可点击、有Ripple和可见交互状态，触区至少48dp；不用emoji、外部图片或新依赖。
- “停止正在进行的发送”作为弱化的独立操作保留，不把未测状态显示成实时网络或设备状态。
- 底部网络建议与安全说明独立分组，保留同网/5GHz或6GHz建议、设备版本建议、画面未加密、内部声音捕获限制、不录麦克风/无远控等真实说明。
-
保留WindowInsets和ScrollView，文本自动换行、不固定卡片高度；横屏仍可滚动，不重新调用home触发清理。主页浅色系统栏图标与离开主页时恢复其他页样式仅按需处理，不改变投屏全窗口逻辑。

## 验证

- 检查diff确保仅主页视觉变化，四入口及权限包装、停止发送调用保持。
- 运行现有test.ps1回归，使用build-apk.ps1构建开发签名APK；不改签名密钥、不提交Git。
- 有设备时验证小屏/横屏/大字体、系统栏与底部手势区域、整卡点击和返回，以及停止发送。无设备明确说明未完成真机视觉验证，不以浏览器模拟原生页面验收。
